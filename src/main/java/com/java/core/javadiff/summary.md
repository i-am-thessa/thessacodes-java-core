# Java Version — Key New Features

| Java Version | Release Type    | Key New Features                                                                                                                                                                                                                                              |
| ------------ | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Java 8**   | **LTS**         | - Lambda Expressions<br>- Stream API<br>- Date and Time API (`java.time`)<br>- `Optional`<br>- Default and Static Interface Methods                                                                                                                           |
| **Java 11**  | **LTS**         | - Standard HTTP Client<br>- Local-Variable Syntax for Lambda Parameters<br>- String API Improvements<br>- HTTP/2 Support<br>- Java Flight Recorder                                                                                                            |
| **Java 17**  | **LTS**         | - Sealed Classes and Interfaces<br>- Pattern Matching for `instanceof`<br>- Records<br>- Enhanced Switch Expressions<br>- Strong Encapsulation of JDK Internals                                                                                               |
| **Java 21**  | **LTS**         | - Virtual Threads ⭐<br>- Sequenced Collections<br>- Pattern Matching for `switch`<br>- Record Patterns<br>- Foreign Function & Memory API<br>- Structured Concurrency *(Preview)*<br>- Scoped Values *(Preview)*                                              |
| **Java 22**  | Feature Release | - Unnamed Variables and Patterns<br>- Statements Before `super(...)` *(Preview)*<br>- Stream Gatherers *(Preview)*<br>- Foreign Function & Memory API *(Final)*<br>- Class-File API *(Preview)*                                                               |
| **Java 25**  | **LTS**         | - Module Import Declarations<br>- Compact Source Files and Instance Main Methods<br>- Flexible Constructor Bodies<br>- Scoped Values<br>- Stream Gatherers<br>- Class-File API<br>- Compact Object Headers<br>- Generational Shenandoah<br>- AOT Improvements |
| **Java 26**  | Feature Release | - HTTP/3 Client Support<br>- AOT Object Caching<br>- Continued Primitive Pattern Matching<br>- Lazy Constants *(Preview)*<br>- G1 Garbage Collector Improvements<br>- Continued JVM Startup and Performance Improvements                                      |
